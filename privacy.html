Privacy

Last updated: 4 November 2026

Agent Config Generator is a static web page. There is no account, no database and no server of ours that receives what you type. We do not use cookies, analytics or advertising.

What stays in your browser

Your choices, the commands you enter and the generated files are computed in your browser. A folder you import from your computer is read in the browser and never uploaded.

So that a reload does not lose your work, the setup in progress (your choices and what was read from the imported project) is saved in this browser's local storage, on your device only. "Clear this setup", at the bottom of the page, deletes it. It never contains your API key, which has its own separate option.

Importing a GitHub repository

When you import a public repository, your browser calls GitHub directly (api.github.com and raw.githubusercontent.com) to list its files and read a few configuration files. GitHub sees these requests, like any visit to GitHub; its privacy statement applies.

The AI-written project guide

This feature is optional and only runs when you click "Write the guide". Your browser then sends, to the provider you chose: the list of file paths of the imported repository, the configuration and documentation files that were read, and the detected stack and commands. Values found in MCP configuration files (tokens, keys, headers) are masked before sending. The provider processes the request under its own terms and privacy policy, and bills it to your account.

  • OpenRouter account: "Connect with OpenRouter" takes you to openrouter.ai, where you sign in and approve a key for this site. You come back here with that key; requests then go to openrouter.ai, which forwards them to the model. You can revoke the key in your OpenRouter settings at any time.
  • Anthropic API key: you paste your own key; requests go to api.anthropic.com.

Keys are kept for the current browser tab only (session storage) and are forgotten when you close it. They are never written to disk by this site, never put in share links and never sent anywhere else.

Share links

A share link contains your setup, compressed, after the # of the address. Browsers do not send that part to the server hosting the page. Anyone who has the link can read what it contains: agents, options, commands, MCP server definitions and, when it fits, the notes kept from your existing instruction files. It never contains your API key or the secret values of your MCP servers.

Hosting

The company hosting the page may keep standard technical logs of requests (such as IP address, date and requested file) for security and operation, as for any website.
